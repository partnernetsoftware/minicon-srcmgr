# MiniCon SrcMgr 0.1.2

Six native cells. The same local and remote Git client, built by its own compiler on its own machine for each declared OS and ISA — and now downloadable for macOS and Linux as well as Windows.

This is the first release with a macOS or Linux archive. Everything 0.1.0 delivered is here; what changed is reach, not features.

- Issuer: `CN=Microsoft ID Verified CS AOC CA 03, O=Microsoft Corporation, C=US` (Microsoft Artifact Signing, Public Trust)
- RFC 3161 timestamp: `http://timestamp.acs.microsoft.com`
- Signing run [42561659574](https://github.com/partnernetsoftware/minicon-srcmgr/actions/runs/42561659574) at source `e898857`, receipt `release_eligible=true`
- The downloaded `win-x86_64` executable was started from a fresh profile and reported `minicon-srcmgr 0.1.2`; a runtime court on those downloaded bytes passed version, trust grant, status, remote list and upstream honesty.

**The macOS and Linux executables are not signed.** macOS has no Developer ID certificate and no notarization, so Gatekeeper will refuse to launch them on first use; see the note under requirements. Linux has no package-manager distribution.

## What you can do

- Open or create a repository, with an explicit trust review before any Git command runs
- Review the exact staged index and commit it
- Remotes: list redacted URLs and refspecs, show upstream distance, fetch one remote with per-ref results and cancellation
- Clone with deferred checkout, and add / set-URL / rename / remove remotes with a credential-free preview
- Set or clear upstream, fetch-then-fast-forward pull that stops on divergence, current-branch push with per-ref results and unknown-outcome reconciliation
- Window actions: `f` fetch, `p` pull, `P` push

## Known limits in this build

These are not qualified and are stated so nobody is misled:

- **Only the Windows x86_64 cell has a GUI journey qualification** (0.1.0). The other five cells are qualified up to: the archive was built on that cell, the executable starts there and performs real Git reads through the product on a fixture. No window was opened on any of them as part of qualification.
- **No macOS signing or notarization.** On macOS 15 or later, clear the quarantine flag once after extracting: `xattr -d com.apple.quarantine minicon-srcmgr`. Without that the system will block the binary.
- **No Chinese localisation.** The interface is English.
- **No in-window Clone form or Remotes panel.** Both exist only as CLI verbs.
- **No merge, rebase or in-app conflict resolution.** Pull is fast-forward only and stops with a review on divergence.
- **No clean-image launch court, no accessibility qualification, no CJK/clipboard composition test, no long-session evidence.**
- **No five-participant usability study.** The first-user journey has been exercised by the maintainer only.
- Git must already be installed and on `PATH` (or pass `--git <path>`), version 2.43 or newer. The product does not bundle Git.
- The Linux archives are built against glibc 2.39 and have only been run on Ubuntu 24.04 runners. Older distributions and musl are not supported.
- The macOS archives are built on macOS 15 runners. macOS 14 is the declared target; running on it is untested.
