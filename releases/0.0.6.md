# MiniCon SrcMgr 0.0.6

Development source checkpoint. GitHub supplies the tagged source archives; no executable or portable ZIP is distributed with this release. The first qualified runnable Windows beta remains the 0.1.0 target.

## Local client

- Welcome, Open/Create, recent repositories and missing-location repair, with separate deliberate repository trust.
- Installed-Git selection/testing and local identity setup with explicit save and truthful refusal states.
- Repository tabs with independent drafts, selection, query and scroll; close/reopen and controlled process restart preserve acknowledged input.
- Named Changes/Diff controls, file/hunk/line stage and unstage, guarded discard/ignore and a complete unfiltered staged-index commit review.
- Literal quick filters for loaded files, branches and commits; filters do not narrow the commit target.
- Reviewed editor/terminal handoff to the selected repository/file using literal arguments.
- Shared caret/selection editing and initial Windows UIA semantics for delivered entry/task controls, plus typed message keys.
- Fix: background refresh of an unchanged file Diff retains navigation made while Git is working. Changed content resets the old line target; retained stale pixels never authorize writes.

Existing local branch, stash and history actions are retained. Clone/authenticated remote exchange, conflict-center and expanded history work remain later increments.

## Verification

The refresh fix passed 92 UI cases and affected all-target Clippy. [Local-client CI](https://github.com/partnernetsoftware/minicon-srcmgr/actions/runs/40102738118) independently passed the shared UI and actual-Git entry/tool/commit/Changes contracts. A deliberate removal of the readiness guard makes the new regression fail; restoring it passes. The optimized source-bound candidate completes 35 actual Diff-navigation trials, including 30 timed inputs independently verified to overlap owned Git process lifetimes.

On the available Windows Server 2022 x64 developer host, the standard fixture has 100k commits, 20k files, 200 refs and 200 changed paths. Actual inspect/stage/commit/branch-return/restart checks preserve the intended Git objects/index and acknowledged draft, with complete owned-process accounting and normal exits. Active-cycle CPU is 20.0 seconds against 16.4375 seconds for the same actual backend command sequence and identical final state; the budget is 21.046875 seconds. Earlier source-bound idle measurements are about 0.026% of one core over 60 seconds; their original source/artifact identity is retained in the plan rather than relabeled as a fresh run.
