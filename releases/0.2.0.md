# MiniCon SrcMgr 0.2.0 beta

**This is a pre-release.** The clean-image and five-participant courts have not
been run, and this page says so rather than implying they passed. Everything
0.1.3 delivered is here, plus the first capability the product never had:
writing an integration.

## What is new since 0.1.3

- **Merge from a reviewed decision.** `m` takes a branch, a tag or an object id;
  the review names one outcome — already up to date, fast-forward, a real merge
  with the commits it combines, or the paths that would conflict — plus the
  branch it moves, both object ids and whether the worktree already holds
  changes. One one-use ticket approves it, and a conflict stop reports the
  paths with HEAD unmoved.
- **Rebase from the same surface.** `b` names the new base and how many commits
  would be replayed; the branch is only moved on approval.
- **A conflict center.** `C` lists every unmerged path with its class —
  content, add/add, delete/modify, symlink, submodule — and shows base, current
  and incoming labelled by stage role, in the interface language. Binary sides
  say so, missing sides say so, cut sides say they were cut.
- **Resolve without leaving the window.** `u` takes the current side, `w` the
  incoming side, each written as the exact object the review showed. `e` opens
  the path in the configured trusted editor and Space stages the edited copy;
  marker-like lines are reported as a warning because they may be deliberate.
- **Continue, skip, abort.** Each follows Git's own state. Skip names the commit
  it drops from the replay; abort states what it restores and re-reads the
  repository afterwards instead of claiming a rollback.
- **A record of a job that never came back.** Every mutation writes a one-line
  record first and clears it when the command returns. A record found at open is
  reported as needing reconciliation until you inspect the repository and press
  `X`.

## What this release does not prove

- **The clean-image court did not run (C6).** Nobody has launched this archive
  on an image that never had the product or the Rust toolchain. The runbook and
  the receipt it produces are in `docs/qualification/clean-image.md`.
- **The five-participant court did not run (C7).** Four of five unaided
  completions of clone → stage/commit → pull → push has not been observed, and
  no participant has been asked to finish a conflicted merge. The protocol is in
  `docs/qualification/five-users.md`.
- **No dedicated three-way merge tool.** The product configures an editor and a
  terminal, not a merge program; the external path is the editor plus Space, as
  described above.
- **No in-app result editor.** The base/current/incoming/result panes with
  search, IME and encoding are 0.2.1. Whole-side resolution and staging an
  edited copy are what this version offers.
- **No GUI journey qualification on any cell for this version.** Only Windows
  x86_64 has ever had a GUI journey qualified (0.1.0); the other cells are
  qualified to "starts and performs real Git reads on a fixture". macOS is not
  signed or notarized: clear the quarantine flag once after extracting with
  `xattr -d com.apple.quarantine minicon-srcmgr`.

## Requirements

Git must already be installed and on `PATH` (or pass `--git <path>`), version
2.43 or newer. The product does not bundle Git. Windows x86_64 needs Windows 10
or later; Windows ARM64 needs Windows 11 on ARM; macOS needs 14 or later; Linux
needs glibc 2.39 (Ubuntu 24.04).
